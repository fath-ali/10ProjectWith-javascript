# Calculator

A simple, modern web calculator with keyboard support.

## Run locally

- Option 1: Open `index.html` directly in your browser.
- Option 2: Serve the directory:

```bash
python3 -m http.server 8000 --directory /workspace/calculator
```

Then open `http://localhost:8000/`.

## Keyboard shortcuts

- Digits: `0-9`
- Decimal: `.`
- Operators: `+ - * /`
- Equals: `Enter` or `=`
- All Clear: `Esc`
- Clear Entry: `Backspace`
- Percent: `%`
- Toggle Sign: Click `±`
